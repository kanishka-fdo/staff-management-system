# Staff Management System

A web-based Staff Management System built using **Spring Boot** to manage employees and departments.

## Features
- Staff & department management (CRUD)
- MVC architecture
- Thymeleaf UI
- Database integration

## Tech Stack

- Java
- Spring Boot
- Spring MVC
- Thymeleaf
- MySQL
- Maven
- HTML/CSS

## Run the Project
```bash
mvn spring-boot:run
